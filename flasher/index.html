Flash Chirp

Install or update the Chirp voice terminal firmware on a T-Embed CC1101 Plus, straight from the browser. (A T-Deck is flashed with PlatformIO instead: see the project README.)

What you need

  • a T-Embed CC1101 Plus
  • a USB-C cable that carries data (charge-only cables will not work)
  • Chrome or Edge on a desktop computer (the installer uses Web Serial; it does not work on phones, tablets, Safari or Firefox)

Install

  1. Plug the device into the computer.
  2. Click Install and pick the device's port. If no port shows up in the list, hold the BOOT button on the device while plugging the cable in.
  3. The installer asks whether to erase the device — leave the Erase device box unticked and click Next. Erasing wipes all device settings; a fresh device does not need it.
  4. Wait for Installation complete. Leave the cable in if you'll set up over USB with host/pair.py (Hermes) or host/provision.py.

After the install

The device restarts into a setup screen: a WiFi network called Chirp-XXXX with its password and a QR code. Join it with your phone, open the page that appears, pick your WiFi and choose Venice (one API key, no computer) or Hermes on my network. For Hermes you can instead finish setup from your Hermes machine with host/pair.py.

Updating an installed device

Updating works the same way: click Install over the existing install. Your WiFi, Venice and Hermes settings are kept — do not tick “Erase device”; that wipes them and you would need to set the device up again.

The flashing runs entirely in your browser (ESP Web Tools, served from this site); nothing is sent to any server.
